# Battleshield deployment

Publish Muse's downloaded Airship Battle 1v1 Godot 4.3 game on the existing GitHub Pages site at `/game-prototypes/battleshield/`, and add a Battleshield link to the prototypes index.

Preserve the imported gameplay, balance, and procedural art. This explicit Godot import is isolated outside the Phaser prototype build. The game uses on-screen buttons and canvas stretching for mouse and touch input; landscape orientation is recommended on phones.

Out of scope: new mechanics, balance changes, replacement artwork, changing other games or hosting providers.
