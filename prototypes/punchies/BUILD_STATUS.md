## Current milestone
Zombie Survival logic ready for Art integration on proto/punchies/zombie-survival. Review only; this assignment does not merge or deploy.
## What was implemented
Seeded multi-enemy combat, closest-target facing locked throughout punches, one contact per enemy per swing, individual stun/knockback, safe edge spawning, crowd separation and active cap. Sixty-second waves; one random existing Easy AI fighter every fifth wave. Kill-based zombie healing, automatic intermission checkpoint, Save & Exit, explicit incompatible balance versions, consumed checkpoints and highest cleared wave with fighter/skin/version. Boss AI state supports deterministic simulation cloning. Typed view/events and integration contract in docs/survival-interfaces.md; placeholder browser harness in tools/survival-review.html.
## Key technical decisions
Regular boxing uses its existing step unchanged; the arena adapter reuses existing combat operations once per entity and contacts per pair. Zombie stats remain Marco with mode-specific HP/speed/damage; visualId selects zombie artwork independently. Surviving timer expiry despawns all enemies including bosses. Death takes priority over expiry. Only zombie kills heal. Existing fighter tune is unchanged; Survival numbers are configurable placeholders in src/survival/config.json. XP, tokens and Elo are disabled. Active attempts cannot resume; checkpoint consumption is saved before next-wave combat.
